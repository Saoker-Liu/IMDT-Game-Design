# 隐蔽暗礁 · v3.3.1

暗礁始终与深海使用同一幅海面，无论是否已经被发现，都不显示岩纹、色差、边界或发现标记。只有已发现格子的鼠标悬停说明和无障碍名称从“深海”变为“暗礁”。正常炮击水花、火焰和舰船残骸按原规则显示。

## 发现方式

- 只有己舰实际触礁才确认暗礁。炮弹和鱼雷攻击无论命中、落空还是击沉，都不会让地形说明变为暗礁。
- 己舰因驶入暗礁而触礁沉没后，确认本次新进入的暗礁格。沉船的其他格子、附近格子及整片暗礁带不会因此被揭示。
- 初始部署和安全通过暗礁不确认地形；未发现格子的说明仍为深海。非法攻击与失败操作不更新情报。
- 触礁发现信息按玩家记录，仅更新该玩家己方棋盘的对应格子。不会自动把已知暗礁坐标发送给对手；敌方棋盘中的暗礁仍显示为深海。
- 局域网对局刷新或重新连接同一会话后保留发现信息，再战重置。

## 范围

保留现有地图布局、25% 触礁概率、初始部署豁免、浅滩与深海鱼雷规则。没有新增独立侦察按钮或地图随机化。

服务端和练习模式共用真实地形判定。玩家视图将未发现暗礁记为深海；AI 也使用这一过滤后的视图。棋盘、预览、图鉴与图例中的暗礁均使用深海素材。原始暗礁绘画保留为存档，网页不再加载。

## 验证

- `npm test`：31 项规则 / HTTP 测试，包括隐藏地形、炮弹与鱼雷不揭示暗礁、触礁确认、信息隔离、刷新恢复和再战重置。
- `npm run check:reefs`：通过真实房间界面开火和触礁，检查炮击后悬停仍为深海、触礁后对应格变为暗礁、相邻格保持隐藏、发现前后海面样式一致，确认预览 / 图鉴 / 手机和人机演习不泄露暗礁。
- `npm run check:charts`：礁石与浅滩轮廓继续精确对齐规则，暗礁没有轮廓。
- 原有地形、舰船与布局浏览器回归及静态构建。
