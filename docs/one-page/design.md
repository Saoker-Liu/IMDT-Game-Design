# 雾海对弈 · FOGBOUND

**读懂迷雾，打出胜机。**

| 平台 | 类型 | 模式 |
| --- | --- | --- |
| PC / 移动端浏览器 | 卡牌驱动 · 隐藏信息 · 回合制海战策略 | 单人剧情战役 / 双人局域网对战 |

## 01 游戏概念

玩家部署一支隐蔽舰队，从侦察与命中线索中推断敌舰位置，以循环手牌安排齐射、侦察和机动，在有限行动中争夺制海权。

## 02 设计目的

以可变舰位、情报时效和卡牌约束，构建持续变化的海战推理与战术取舍。

## 03 体验目标

从发现线索的期待，到锁定目标的确信，再到齐射命中的满足与局势逆转的紧张。

## 04 故事与游戏模式

潮汐星的海权争夺战中，玩家率领舰队夺取港口、航路与中央海域。

**单机「雾海争霸」**：六关串联远征，以进攻为主，穿插护港防守。

**双人对战**：以相同战术语言与真人博弈；人机演习提供练习入口。

## 05 核心玩法机制

| 机制 | 决策与作用 |
| --- | --- |
| 隐蔽布阵 | 编组舰队，利用海域与地形部署；双方舰位彼此隐藏。 |
| 循环出牌 | 以行动力安排本轮组合；用过的牌回到牌库，影响后续选择。 |
| 侦察与齐射 | 照明捕捉局部舰影，结合命中线索判断，以 2×2 齐射打击。 |
| 机动与反制 | 舰艇移动使旧情报过期；岛礁遮挡与航行风险改变攻防决策。 |

## 06 玩家为什么持续游玩

每次移动都会改变情报价值，每轮手牌都会重排战术选择。单机以新舰艇、装备和任务逐关拓展解法；对战由对手的判断与反制造变化。消灭敌舰或完成关卡目标获胜，舰队全灭或守港失败则落败。

## 主视觉说明

**海面之下是未知，手牌之中是选择。**

深海蓝、黄铜刻度与微缩舰船构成海战指挥台。用水花、火焰与残骸，清楚反馈每次判断的结果。
